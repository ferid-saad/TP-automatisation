## 📖 Aperçu

Ce dépôt contient une collection de **scripts d'automatisation** pour simplifier et accélérer les tâches répétitives en développement et administration système.

## 🛠 Technologies

- **Python 3.8+** - Scripts principaux
- **Bash/Shell** - Automatisation système
- **Git** - Automatisation de workflows
- **Outils système** - Divers utilitaires

## ⚡ Installation Rapide

```bash
# Cloner le dépôt
git clone https://github.com/ferid-saad/TP-automatisation.git
cd TP-automatisation

# Rendre les scripts exécutables
chmod +x scripts/*.sh
chmod +x scripts/*.py
```
